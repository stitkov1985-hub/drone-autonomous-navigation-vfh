# Программный комплекс автономной навигации и 3D-картографирования БПЛА в лесистой местности

Данный репозиторий содержит выпускную квалификационную работу по программе **«Программист дронов»**. Проект представляет собой автономную программную систему на базе операционной системы **ROS (Robot Operating System)**, обеспечивающую безаварийное прохождение квадрокоптера сквозь неизвестную плотную среду с препятствиями с одновременным выстраиванием цифрового двойника пространства в реальном времени.

## 🛠️ Технологический стек проекта
* **ОС робота:** ROS Noetic / Ubuntu 20.04 LTS (Развернуто в изолированном Docker-контейнере)
* **Автопилот:** PX4 Autopilot (SITL)
* **Протокол связи:** MAVROS / MAVLink
* **Симулятор:** Gazebo Classic
* **Визуализация:** RViz

## 🧠 Ключевые программные узлы (Папка `src/`)
1. `vfh_planner_node.py` — Ядро локальной навигации. Реализует алгоритм **VFH (Vector Field Histogram — метод векторных полярных гистограмм)**. На основе данных 2D-лидара выстраивает полярную гистограмму плотности препятствий и уводит БПЛА по безопасному вектору (калиброванный радиус безопасности робота \(R_{safe} = 0.7\) м).
2. `mapping_node.py` — Программный узел 3D-картографирования. Осуществляет динамический пересчет полярных координат облака точек лидара из подвижной СК датчика в глобальную фиксированную СК карты (`odom`). Дискретизирует пространство в виде трехмерных кубиков-вокселей и экспортирует геоданные в постоянную базу данных `voxel_map_database.txt`.
3. `straight_planner_node.py` — Узел полетного задания, задающий глобальную целевую уставку (60 метров вперед по оси X к береговой линии). Поддерживает интерактивный перехват цели по клику мыши через топик `/move_base_simple/goal` из RViz.
4. `draw_swarm.py` — Автономный скрипт постобработки данных «черного ящика» (`.bag`-файлов) и автоматической генерации графика траектории полета с наложением точных координат 65 деревьев и антропогенных препятствий полигона.

## 🚀 Порядок запуска дипломной миссии
Для запуска всей цепочки навигационных и картографических нод внутри контейнера используются следующие команды:

```bash
# 1. Запуск симуляционного полигона леса (65 деревьев + океан)
./scripts/start_sim_docker.sh -c px4_simulation

# 2. Активация локального планировщика VFH
rosrun drone_sim vfh_planner_node.py

# 3. Запуск узла 3D-картографирования вокселей
rosrun drone_sim mapping_node.py

# 4. Включение визуализатора RViz
rosrun rviz rviz

# 5. Запуск полетного задания
rosrun drone_sim straight_planner_node.py
```

## 📊 Результаты моделирования
Программный комплекс успешно прошел натурные испытания в сверхплотной симуляционной среде. Зафиксирована высокая сходимость алгоритма VFH: БПЛА выполнил сквозной полет, совершая плавные синусоидальные маневры уклонения от стволов деревьев и крупногабаритного мусора, и успешно зафиксировал позицию в финальной точке над водной гладью океана. Коллизий и сбоев автопилота не зафиксировано.

## 📚 Используемые источники и официальная документация
При проектировании архитектуры ROS-нод, калибровке алгоритма локальной навигации VFH и разработке системы 3D-картографирования использовались следующие официальные спецификации, репозитории и стандарты:

1. **Официальная документация экосистемы ROS (Robot Operating System)** — Спецификации обмена данными между узлами через ROS-топики, механизмы подписки/публикации и пакет трансформации систем координат `tf`: [https://ros.org](https://ros.org)
2. **PX4 Autopilot User Guide** — Руководство по настройке полетного контроллера, режима `OFFBOARD` и архитектуры PX4 SITL (Software-in-the-Loop): [https://px4.io](https://px4.io)
3. **Репозиторий PX4-Autopilot** — Исходный код автопилота и базовые SDF-модели квадрокоптера Iris для симулятора Gazebo Classic: [https://github.com](https://github.com)
4. **PX4 Avoidance Repository** — Примеры построения систем облета препятствий и локального планирования траекторий БПЛА: [https://github.com](https://github.com)
5. **Документация Point Cloud Library (PCL)** — Алгоритмы обработки трехмерных облаков точек лидара, фильтрации шумов и дискретизации воксельных сеток: [https://pointclouds.org](https://pointclouds.org)
6. **Документация MAVROS** — Спецификации пакета связи между ROS и полетными контроллерами по протоколу MAVLink: [http://ros.org](http://ros.org)
7. **IEEE Xplore Digital Library (Оригинальное описание алгоритма VFH)** — Научная публикация авторов метода (Й. Боренштейн и И. Корен, 1991 г.) «The Vector Field Histogram — Fast Obstacle Avoidance for Mobile Robots»: [https://ieeexplore.ieee.org/document/88137](https://ieeexplore.ieee.org/document/88137)
8. **Semantic Scholar (Аналитический обзор локального планирования)** — Международная база академических публикаций, использованная для анализа математических ограничений потенциальных полей и гистограмм: [https://www.semanticscholar.org/](https://www.semanticscholar.org/)
9. **OctoMap Framework** — Базовый открытый проект и библиотека трехмерного воксельного картографирования, чья логика дискретизации ячеек легла в основу нашего узла `mapping_node.py`: [https://github.io](https://github.io)
10. **MathWorks Navigation Toolbox** — Математические спецификации, графические модели и формулы практической верификации полярных гистограмм VFH от разработчиков среды MATLAB/Simulink: [https://www.mathworks.com/help/nav/ref/vectorfieldhistogram.html](https://www.mathworks.com/help/nav/ref/vectorfieldhistogram.html)
11. **Open Source Robotics Foundation (OSRF)** — Официальный портал поддержки стандартов открытой робототехники, на чьих спецификациях строилась интеграция симулятора Gazebo с пакетами MAVROS: [https://osrfoundation.org](https://osrfoundation.org)
12. **Docker Hub (Официальный реестр контейнеризации)** — Использовался для подтяжки базовых образов операционной системы Ubuntu с уже развернутыми мета-пакетами ROS Noetic и PX4 SITL, что обеспечило стабильность и кроссплатформенность проекта: [https://docker.com](https://docker.com)
13. **Gazebo Fuel (Официальный репозиторий 3D-моделей)** — База данных трехмерной параметрической графики, откуда были импортированы наши реалистичные модели деревьев (tree_simple), коробки и поддоны для создания лесного полигона повышенной сложности: [https://gazebosim.org](https://gazebosim.org)
14. **GeeksforGeeks (Математические алгоритмы на Python)** — Техническая база данных, использованная для оптимизации кода и быстрой реализации математической модели Dead Reckoning (счисления пути по времени и мощности) в наших Python-нодах: [https://geeksforgeeks.org](https://geeksforgeeks.org)
